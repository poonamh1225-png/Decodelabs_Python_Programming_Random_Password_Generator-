# Random Password Generator

A simple Python program that generates a random password based on the length entered by the user.

## Features

- Takes password length from the user
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Ensures at least one character of each type
- Handles invalid input

## Technologies Used

- Python
- Random module
- String module

## How to Run

1. Open the project in VS Code.
2. Run `password_generator.py`.
3. Enter the desired password length.
4. The program will generate a random password.
